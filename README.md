# Solar Scada EL

## Описание проекта

Проект посвящен анализу данных солнечных электростанций и прогнозированию выработки электроэнергии на основе SCADA-данных и метеорологических измерений.

## Часть I. Прогноз выработки солнечной станции

Используются данные:

- `Plant_1_Generation_Data.csv`
- `Plant_1_Weather_Sensor_Data.csv`
- `Plant_2_Generation_Data.csv`
- `Plant_2_Weather_Sensor_Data.csv`

<img width="868" height="470" alt="image" src="https://github.com/user-attachments/assets/9ec9f6c6-bda3-415b-b159-92543558f55d" />


Основные задачи:

- загрузка и предварительная обработка данных;
- анализ солнечной генерации;
- учет метеорологических факторов;
- построение модели прогноза мощности;
- визуализация результатов.

## Часть II. Дефектоскопия элементов по EL-снимкам

Вторая часть проекта связана с анализом electroluminescence images солнечных модулей для выявления дефектов.
